# Curadoria do projeto

Espaco para registrar a avaliacao tecnica, organizar o backlog e manter uma
visao de evolucao do Document Management System (DMS).

- [Avaliacao tecnica](avaliacao.md): aderencia observada, evidencias, riscos e
  limites desta revisao.
- [Backlog priorizado](backlog.md): trabalho futuro com prioridades e criterios
  de aceite verificaveis.
- [Visao futura](visao-futura.md): evolucao proposta em fases, respeitando as
  restricoes atuais de armazenamento local.

O [changelog](../CHANGELOG.md) registra mudancas funcionais. O arquivo
`historico-treinamento.md` continua sendo o registro das etapas do treinamento;
os dois documentos tem propositos diferentes.
